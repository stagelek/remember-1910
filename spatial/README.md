# 공간 추적 현장 테스트 · 2026-11-10

운영 주소: https://stagelek.github.io/remember-1910/spatial/?content=card
content 값: flower, stairs, card, women, brothers.
기존 이미지 AR, 개별 QR, 모델 자산은 변경하지 않음. 이 디렉터리만 추가.

## 실행
1. iPhone Safari 또는 Android Chrome으로 열기.
2. 콘텐츠 선택 → 공간 AR 시작 → 카메라/동작 센서 허용.
3. 무늬가 있는 주변을 천천히 비춰 초기 공간 인식 대기.
4. 표시한 공통 바닥 시작점에서 정해진 방향을 향하고 정면 기준 배치.
5. 최초 거리는 2m, 카메라 높이는 1.5m의 임시값. 실제값으로 조절 후 재배치.
6. 배치 후 그림 없이 둘러보기. 화면 터치로 조정 메뉴/종료 표시.
7. 폭, 좌우, 높이, 앞뒤, 방향 조절 → 기기 저장 또는 설정 링크 복사.
8. 조정 링크를 다른 휴대폰에서 열어도 같은 시작점/방향에서 다시 배치해야 함.

폭은 전체 모델 폭. 높이는 모델의 바닥 기준 높이 오프셋. 앞뒤 +는 최초 정면 방향으로 멀리, 좌우 +는 오른쪽.
최초 거리/카메라 높이 변경은 재배치부터 적용. 모델의 곡률/인물 상대 간격/애니메이션은 재편집하지 않음.
저장은 상대 설정값만 포함하며 XR 세션 좌표는 저장하지 않음. 기기별 localStorage 실패 시 설정 링크/JSON 다운로드 이용.

## 콘텐츠 배치 의도
- 꽃밭: 외부에서 내부 흰색 바닥을 바라보며 바닥 전체 꽃밭. 기존 이미지 AR 모델을 -90도 X 회전해 바닥 방향 복원.
- 독립의계단: 계단을 감싸는 곡면 벽돌벽. 기존 곡률 유지. 정확한 곡률·벽 치수는 미확정.
- 수형기록카드: 복도 끝 정면 벽돌벽. 초기 전체 폭 약 2.694m, 실측 전 임시값.
- 여옥사: 감방 내부 바닥에 여성 두 명. 입구에서 관람.
- 이석영6형제: 야외 잔디밭. 최초 정면 거리 2m. 기존 6인 모델 전체 폭 약 12.64m. 한 명씩 보이는 시야/간격 검증 필요.

## 무료 엔진 / 라이선스
기본 경로는 @8thwall/engine-binary 1.0.0의 배포용 SLAM 엔진.
공식 npm에서 내려받아 dist 전체를 수정 없이 자체 호스팅. 가입/구독/API키 없음.
완전한 MIT 오픈소스 SLAM이 아니며 XR Engine License Agreement 적용.
라이선스/저작권/무보증 고지를 시작 화면 및 조정 메뉴에 표시.
원문: vendor/8thwall/LICENSE
공식: https://8thwall.org/docs/open-source
공식 FAQ: https://8thwall.org/docs/migration/faq
추가 유료 서비스/결제/가입은 진행하지 않음.
Android WebXR는 별도 비교 경로. ARCore 서비스 필요. 기본 8th Wall 경로는 외부 AR 앱을 호출하지 않음.

## 검증과 한계
- 실제 Chrome 브라우저: 자체 호스팅 엔진 로드, 카드 3D 표시, 메뉴 숨김/터치 재표시/종료 확인.
- Node 모의 테스트: 5종 GLB 정규화 방향·실제 폭 계산, 5 WebXR+5 SLAM 세션 시작/배치/종료, 추적 상실/재개, 설정 저장/지원 미검출 처리.
- 공식 npm SHA512 및 vendor 원본 동일성, 변경 전 백업 ZIP CRC 확인.
- 실제 iPhone/Android 카메라 SLAM 성능, 절대 스케일 수렴, 장시간 드리프트, 다중 기기 정합은 미검증.
- 장소 자동 재인식/VPS/공유 앵커/영구 앵커는 구현하지 않음. 매 세션 수동 공통 기준 정렬.
- 실물 벽·문·사람에 의한 가림/마스킹 및 꽃밭 방 경계 자르기는 구현하지 않음.
- 초기 센서·카메라 허용과 브라우저/기기 차이 때문에 현장에서 위치·크기만 조절하면 반드시 끝난다고 보장할 수 없음.
- 계단에서는 평평한 대기 공간에서 테스트. 기존 관람객용 QR는 이 테스트본으로 변경하지 않음.
